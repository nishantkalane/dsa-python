# 🧠 Observations

While solving each pattern, ask yourself:

- What determines the number of rows?
- What determines the number of columns?
- How many stars/numbers/spaces are printed on each row?
- Can I derive a formula instead of memorizing the pattern?

---

# 💡 General Rules

### Rule 1
Outer loop → Controls **Rows**

### Rule 2
Inner loop → Controls **Columns**

### Rule 3
Print statement → Decides **what** gets printed

### Rule 4
Observe each row before writing code

# 🚀 Key Takeaway

**Don't memorize patterns.**

Every pattern can be solved by answering two questions:

1. **How many rows do I need?**
2. **What should I print in each row?**

Once you can answer these, the code becomes straightforward.
