# Python Basics for DSA

A collection of Python concepts and examples needed to get started with **Data Structures and Algorithms (DSA)**.

## 📚 Topics Covered

* Variables & Data Types
* Input & Output
* Operators & Conditions
* Loops
* Functions
* Lists & Strings
* Tuples, Sets & Dictionaries
* List Comprehension
* Useful Built-in Functions
* Common DSA Patterns
* Time Complexity
* Common Python Mistakes

## 🎯 Goal

Learn enough Python to focus on **solving DSA problems instead of struggling with Python syntax**.

> **Learn Python → Practice → Solve DSA → Repeat**
